# Moodboard Generator

A web-based moodboard generator designed to help users build visual concepts by exploring different combinations of **styles, colors, materials, and furniture**.

## Overview

The Moodboard Generator guides users through a simple visual process:

1. Choose a visual style.
2. Select a color palette.
3. Explore materials.
4. Add furniture and visual elements.
5. Generate a final moodboard based on their selections.

The project focuses on making the early stages of visual exploration more structured, intuitive, and engaging.

## Design Process

The project combines **UX/UI design and front-end development**, with a focus on visual hierarchy, interaction, and progressive decision-making.

Rather than presenting all options at once, the experience breaks the moodboard creation process into smaller steps, allowing users to gradually define the direction of their concept.
